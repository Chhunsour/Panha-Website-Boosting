# MR PANHA DIGITAL — #1 Social Media Growth Agency Website

Official high-performance landing page and web application for **MR PANHA DIGITAL**, Cambodia's leading social media growth and follower acceleration agency.

![MR PANHA DIGITAL Preview](assets/hero-growth.jpg)

---

## 🌟 Key Features

- ⚡ **Interactive Live Growth Engine Console (v3.2)**: Real-time interactive simulation for Facebook, Instagram, TikTok, and Telegram with live growth trajectories and custom tier selection.
- 🎨 **Ultra-Clean Light Aesthetic**: Tailored for maximum conversion with pure white backgrounds, subtle frosted glass panels, and electric cyan/blue accents.
- 🚀 **Hardware-Accelerated GSAP Animations**: Smooth reveal animations, magnetic buttons, and 3D perspective hover cards powered by GSAP & ScrollTrigger.
- 🇰🇭 **Bilingual Typography & Full Localization**: Native Khmer typography (`Kantumruy Pro`) paired with modern English (`Plus Jakarta Sans`) and Bakong KHQR / ABA Bank payment integration.
- 📱 **100% Mobile Responsive**: Fluid responsiveness with mobile drawer navigation, responsive grid layouts, and touch-friendly controls.
- 🔒 **Zero-Password Security Guarantee**: 100% safe, non-drop lifetime refill warranty, and instant Telegram checkout.

## 🚀 Quick Start (Local Development)

To run the project locally without any dependencies:

```bash
# Python 3
python3 -m http.server 4321

# Or with Node.js
npx serve .
```

Visit `http://localhost:4321` in your browser.

---

## 🌐 Deployment on Vercel

This repository is pre-configured for static zero-config deployment on Vercel:

1. Import the repository `Chhunsour/Panha-Website-Boosting` in your [Vercel Dashboard](https://vercel.com).
2. Framework Preset: **Other** / **Static HTML**.
3. Output Directory: `./` (Root).
4. Click **Deploy**.
